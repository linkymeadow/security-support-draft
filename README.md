# 국내 웹 생태계를 위한 보안 지원 제안

국내에서 웹서비스를 이용하고, 만들고, 운영하는 개인·기업·기관 모두를 위한 보안 지원의 방향을 논의하는 제안 초안입니다.

필요한 보안 지원과 고려사항을 정리해, 이를 만들거나 개선하려는 주체가 참고할 수 있도록 제안합니다. 보안 도구나 플랫폼을 직접 구축·운영하는 사업은 아니며, 상세 기술 설계와 구현 코드는 다루지 않습니다.

## 문서 목차

상세 내용은 주제별 문서에 정리하고, 논의가 구체화되면 문서를 추가합니다.

- [제안이 필요한 배경](proposal/background.md)

  반복되는 보안 문제, AI로 달라진 개발·공격 환경과 운영의 어려움을 바탕으로 제안이 필요한 이유를 설명합니다.

- [익숙한 서비스 이름에서 시작하는 보안 안내](proposal/service-environment-guidance.md)

  익숙한 업체·제품명에서 시작해 사용 중인 프로그램과 관리 범위를 확인하고, 모르는 내용은 담당자에게 물어볼 수 있는 안내를 제안합니다.

- [보안 용어를 이해하고 다음 행동을 알 수 있도록](proposal/plain-language-guidance.md)

  어려운 용어를 쉬운 말로 풀고, 상황과 역할에 맞춰 확인할 일과 담당자에게 물어볼 내용을 안내하는 자료를 제안합니다.

- [보안 공지를 확인과 조치로 이어갈 수 있도록](proposal/security-notice-guidance.md)

  보안 공지가 사용 환경에 해당하는지 확인하고, 담당자 문의와 조치 결과 확인까지 이어지는 지원을 제안합니다.

- [보안 조치의 이유를 쉽게 설명할 수 있도록](proposal/security-control-reasons.md)

  보안 조치의 필요성과 시간·인력 지원을 설명하는 템플릿을 지침에 포함하고, 주기적인 점검과 개선을 성과 평가와 투자에 반영하는 방향을 제안합니다.

- [개인정보 보호, 무엇을 어떻게 해야 하는지 알 수 있도록](proposal/privacy-guidance.md)

  개인정보의 보관·조회 방법을 쉬운 사례로 설명하고, 사람과 AI가 함께 확인할 점검표의 구성 방향을 제안합니다.

- [문제를 분석하고 이상 징후를 알아차리기 위한 기록](proposal/logging-guidance.md)

  민감정보를 제외하고 필요한 기록을 남기는 방법, 서버와 통신의 변화 확인, AI 분석 시 기록을 보호하는 방법을 설명합니다.

## 목적을 다한 뒤에는

제안의 목적을 다하면 이 저장소를 아카이브합니다(새로운 변경을 받지 않고 기록으로 보관). 이후에는 문서 갱신과 새로운 의견·수정 요청의 검토를 종료하며, 남아 있는 내용은 마지막 작성 시점의 제안 기록으로 보관합니다.

## 보증 부인

이 저장소의 문서와 예시는 검토·토론을 위한 초안으로, 있는 그대로 제공합니다. 법령이 허용하는 범위에서 내용의 정확성·완전성·최신성, 특정 환경에 대한 적합성이나 적용 결과를 보증하지 않습니다. 이 자료를 참고하거나 따랐다는 사실만으로 시스템의 안전이나 침해 예방이 보장되는 것은 아닙니다.

이 자료는 개별 시스템의 보안 진단이나 상황에 맞는 전문적 검토를 대신하지 않습니다. 실제 적용 전에는 최신 공식 자료와 자신의 환경을 확인해야 합니다.

이 저장소의 운영자·문서 작성자·기여자는 자료의 이용 또는 이용 불가로 발생하는 손해에 대해 법적 책임을 지지 않습니다. 이 책임 제한은 법령이 허용하는 범위에서 적용되며, 법률상 배제하거나 제한할 수 없는 권리나 책임에는 영향을 주지 않습니다.
